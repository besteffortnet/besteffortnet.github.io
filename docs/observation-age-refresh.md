# 開いたままの観測時刻の鮮度表示

一覧で観測時刻を一度取得した後、ページを開いたまま25分を超えても表示が「観測時刻」のまま残り、再取得しない限り古い観測と区別できなかった。取得済みの時刻から表示を再計算し、25分を超えたら「前回の観測」に切り替える。Comic Shelfの小さい欄でも「観測」から「前回」へ切り替える。

- 新鮮な表示が古くなる時刻に一度だけタイマーを設定する。非表示中はタイマーを外し、表示に戻ったときと履歴から復帰したときに再計算する。
- 時間の再計算では状態APIを再取得しない。同じ表示を書き直さず、不要な読み上げや再描画を避ける。
- 手動再取得の開始時は以前の時刻を破棄する。取得が失敗した後に以前の表示を復活させない。
- 判定は端末の時計に依存する。非表示・停止中はブラウザによってタイマーが遅れることがあり、表示復帰時に再計算する。観測時刻はサービスの現在の稼働状態を保証しない。

優先度は86点（利用価値31/35、共通性23/25、実現性17/20、検証・復旧15/20）。開きっぱなしの画面で古い観測を新しいものと誤認しにくくし、追加通信を避けることを重視した事前評価である。誤認率や通信量の長期実測ではない。サービス自体や定期収集は変更せず、一覧の版履歴から固定版へ復元できる。
