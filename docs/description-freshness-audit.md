# 一覧の固定された版・サイト数の点検

一覧の概要に現在値として版番号やサイト数を固定すると、実アプリが更新された後も古い情報が残る。2026年11月4日、共通化アプリの概要は `v0.3.2` と `17サイト` のままだった一方、同アプリのトップの版表示は `v0.3.9`、サイト適用診断APIのカタログと保存済み結果はそれぞれ21サイトだった。概要から固定値を外し、最新の版はアプリ側で確認できるようにした。

```sh
python3 tools/audit_observation_mapping.py
```

出力の `description_review_candidates` は、カードの概要にある `v1.2.3` 型の文字列や `17サイト` 型の表記を確認候補として示す。リポジトリ、カード番号、該当文字列のみを出力し、概要全文は出力しない。候補は古いと断定せず、停止中・認証が必要・履歴を示す表記などは別途確認する。各項目は20件まで表示し、超える場合は `truncated` を示す。バージョン表記の全種類や文脈を網羅するものではない。

GitHubへのpushとプルリクエスト時にも、この結果をActionsのログへ出す。自動検査は一覧ファイルを読むだけで、LANへの接続や実アプリの版取得は行わない。
