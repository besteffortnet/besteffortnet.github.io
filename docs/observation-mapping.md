# 一覧と観測対象の対応検査

アプリ一覧の「状態」リンクと観測時刻が別のIDを指すと、同じカードで異なる入口の情報を見てしまう。通常の状態表示はそのままに、カード内のリンクと観測ID、対象の重複、取得先の形式を自動検査する。HTTP 8012と追加HTTPS 8019は独立した観測対象のため、Comic Shelfではそれぞれのリンクと時刻を区別する。

## 確認方法

```sh
python3 tools/audit_observation_mapping.py
```

このコマンドは静的HTMLだけを読み、通信や書込みをしない。状態リンクと観測IDの不一致、不正な遷移先、重複ID、取得ボタンの設定違いなどを非ゼロで返す。状態リンクのないカードは番号とリポジトリを報告し、それだけでサービス停止とは判定しない。GitHub Actionsでも同じ契約をPythonテストで検査する。

信頼済みLANから実際の観測JSONと照合する場合は、取得を別の読取操作として行える。

```sh
curl --fail --silent --show-error --max-time 8 \
  -H 'Origin: https://besteffortnet.github.io' \
  'https://192.168.68.221:8013/api/public-observation-times' | \
  python3 tools/audit_observation_mapping.py --observation-json -
```

JSONはサイズ・形式・時刻とIDの一意性を検査する。`linked_but_not_in_snapshot` と `in_snapshot_but_not_linked` は対応差であり、通信失敗や稼働停止を表すものではない。取得時刻は収集時点の情報で、検査時刻の稼働を保証しない。実行環境の証明書信頼とLANへの到達が必要。

## 根拠と範囲

2026年11月4日にCA検証付きGETで得た21観測IDを照合したところ、修正前の一覧は20 IDと対応し、`comic-https` が未掲載だった。修正候補では21 IDが対応し、資料リンク1件は観測リンクなしと表示された。この差の解消はリンク対応の確認であり、利用者端末からの可用性や実機操作の保証ではない。

優先度は85点（利用価値31/35、共通性22/25、実現性17/20、検証・復旧15/20）。複数入口を別サービスとして誤認しないことと、今後の設定変更時に不一致を検出できることを重視した事前評価であり、障害率や時間短縮の実測値ではない。既存の状態画面や定期収集は変更しない。一覧を戻す場合は版履歴の固定版復元手順を使う。
